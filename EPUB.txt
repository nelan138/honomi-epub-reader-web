EPUB File
  ↓
container.xml
  ↓
OPF Package Document
  ├── Metadata  → Bookshelf title, author, language
  ├── Manifest  → Files, cover, chapters, CSS, images, fonts
  ├── Spine     → Default chapter reading order
  └── Navigation → Table of contents

---

container.xml
  → tells you where the OPF file is

OPF metadata
  → tells you what the book is

OPF manifest
  → tells you what files exist and where they are

OPF spine
  → tells you which manifest files form the reading order

Manifest
  → connects IDs to actual file paths

Navigation document
  → provides the table of contents

Original EPUB file
  → provides the actual XHTML, CSS, images, fonts, and other resources
